# Skills de conteúdo

Este repositório contém skills portáveis no formato Agent Skills.

- Antes de traduzir ou revisar uma tradução em `content/`, leia e siga `.claude/skills/mitzideas-translation/SKILL.md`.
- Antes de definir ou alterar `categories` ou `series` em um post, leia e siga `.claude/skills/mitzideas-taxonomy/SKILL.md`.
- Use `.claude/skills/humanizer/SKILL.md` somente quando o usuário pedir para humanizar ou revisar texto gerado por IA. Não aplique essa transformação automaticamente a texto já autoral.
- Em ambos os casos, preserve código, front matter, URLs, caminhos de assets e sintaxe Hugo/Markdown conforme as instruções da skill.
